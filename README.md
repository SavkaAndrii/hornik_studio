# Hornik Studio — Vanilla HTML, CSS & JavaScript

## Запуск

Відкрийте `index.html` подвійним натисканням у звичайному браузері. Сайт використовує відносні шляхи, звичайний defer-script, локальні ресурси та не потребує npm, сервера або збірки.

## Що змінено

Вихідна версія вже була на HTML/CSS/Vanilla JS. Фреймворків і залежностей для видалення не було. Збережено всі тексти, адреси anchor-посилань, ідентифікатори секцій, кольори, шрифти, основні розміри, відступи, сітки та оригінальні WebP без перекодування.

- Уся розмітка залишилась у `index.html`. Навігація отримала семантичний список `menu__list` / `menu__list-item` / `menu__list-link`.
- Узгоджено BEM-назви: `main-screen__*`, `services__*`, `portfolio__*`, `contacts__*`, `header__logo`, `footer__inner`.
- Єдиний файл стилів — `css/style.css`, із секційними коментарями та розгорнутими деклараціями. Дизайн-токени — у `:root`.
- Зображення й favicon перенесені до `images/`.
- Додано наданий бурштиновий символ біля HORNIK STUDIO у header та footer. `logo.webp` — оптимізована копія 144×144, `logo-original.png` — повний незмінений оригінал. Маленький favicon залишено спрощеною літерою H, оскільки деталізований дракон погано читатиметься на 16 px.
- Нові ефекти: послідовна поява hero-тексту, поява зображення з декоративними лініями, коротке делікатне пульсування світла, паралакс до 3 px, мідне світіння карток, проявлення підписів портфоліо, підсвічування етапів і ліній процесу, підкреслення меню та зміна фону header після прокручування hero.
- Лінії hero є частиною оригінального растра: їх не перероблено й не відокремлено, вони проявляються разом із зображенням.

## Функціональність та продуктивність

`js/main.js` не генерує розмітку. Збережено меню, Escape, фокус після переходу, active navigation, IntersectionObserver та захист форми від надсилання. Форма, як і раніше, лише демонстраційна: кнопка disabled, жодного фальшивого повідомлення про успіх.

Паралакс працює лише з точним курсором на ширині понад 760 px, максимум один update за кадр. Немає безперервного animation loop. Слухачі знімаються, коли hero поза екраном, вкладка прихована або увімкнено reduced motion. Єдині динамічні inline-властивості — `--parallax-x/y`. Пульсування обмежене трьома циклами за появу hero. Hover-збільшення портфоліо та всі попередні ефекти збережені; reduced motion вимикає анімації.

## Редагування

- Тексти, контакти, проєкти, `alt` та посилання: `index.html`.
- Кольори, шрифти, відступи: `:root` у `css/style.css`.
- Базові секційні стилі й responsive-правила — на початку/в середині CSS; нові ефекти — наприкінці з окремими коментарями.
- Логотип: `images/logo.webp`; оригінал збережений поруч.
- Інтерактивність: `js/main.js`.

## Перевірки та межі перевірки

У цій ітерації пройшли: перевірка синтаксису JS; порівняння всіх текстів, посилань і id з оригіналом; перевірка ресурсів; побайтове порівняння старих зображень; перевірка відсутності HTML-генерації, inline CSS у HTML, мережевих запитів і залежностей. Перевірено JS-обробники меню, Escape, фокус, observer-анімації, reduced motion, зміну desktop/mobile режиму та зупинку паралаксу через ізольовані тести.

Важливо: браузерна політика середовища заблокувала `file://`. Тому фактичний запуск через подвійний клік, нове візуальне порівняння, консоль у браузері й вимірювання мобільної продуктивності в цій ітерації НЕ підтверджені. Статичні перевірки не замінюють браузерні. Перед публікацією відкрийте сторінку у звичайному браузері та перегляньте 320/390/820/1280 px, усі секції, меню, кнопки та reduced motion.
